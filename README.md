
# Lorbeerblatt – Canteen Menu App

**Lorbeerblatt** is a modern, mobile-friendly theme for presenting canteen meals, originally created years ago and recently refreshed.

## 🌍 Live-Demo

The latest version of this project is automatically deployed at:
👉 [https://transfairs.github.io/ui-design-canteen/](https://transfairs.github.io/ui-design-canteen/)

Feel free to explore the menu, switch between light and dark mode, and try out the interactive rating system.


## ✨ Features

- 🌗 Light/Dark Mode toggle
- 🌿 Leaf-based dish rating
- 📱 Responsive design
- 📷 Image support and fallback graphics

## 📁 Project Structure

```
index.html           # Today's menu
dish.html            # Detail view with ratings
week.html            # Weekly overview
archive.html         # Past dishes
contact.html         # Contact form
legal.html           # Legal information

/css/                # Styles
/js/                 # Dark mode & rating logic
/images/             # logo, fallback images
```
